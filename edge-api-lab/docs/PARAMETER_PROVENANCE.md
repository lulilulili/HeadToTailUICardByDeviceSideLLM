# 单服务参数溯源（2026-10-12）

本次只落实单服务阶段相关的工程建议：逐参数来源、可核验原文证据、解析依赖，以及未确定显式目标时禁止缓存系统值兜底。没有新增跨服务规划、第三方执行、MCP、联网搜索、习惯收集或主动服务。

## 不给小模型增加负担

`explicit-v7` 提示词、API 候选与模型输出 Schema 均不变，模型仍输出 `{domain,api,arguments}`。来源不让模型自报，由原文核对和解析程序在模型调用之后生成；没有新增模型调用，也没有来源标签带来的额外输入/输出 token。

保留 `modelArguments`、`extractedArguments` 和 trace，不改模型原始表现。旧 `resolved.sources` 保持兼容，但其中的 `user` 不能证明已经核验原文。新审计在 `resolved.provenance`，缺少审计的旧记录明确标为旧记录，不补造历史来源。

## 紧凑协议 v1

```json
{
  "v": 1,
  "p": {
    "time_ref": {
      "s": "U",
      "e": [{"b": 2, "e": 4, "t": "明天"}],
      "d": [{"s": "S", "k": "now", "o": "provided_context"}]
    }
  }
}
```

- `v`：审计协议版本；`p`：按参数路径索引，例如 `changes.title`。
- `s`：来源标签。`U` = 可核验用户原文，`S` = 系统/实验环境状态，`C` = 可信用户选择，`D` = 契约默认，`R` = 规则派生，`X` = 尚未核实。
- `e`：原文证据数组；每项 `b` 为起点、`e` 为终点、`t` 为原文。下标使用 JavaScript UTF-16 半开区间，必须可由 `text.slice(b,e)` 还原。枚举映射和 JSON 解码后的值不要求与原文字面相同，仍保留真实片段。
- `d`：依赖记录数组；`k` 为依赖键，`s` 为依赖来源。来源与依赖分开，避免把用户明确的“明天”标成系统猜测。
- `o`：来源细分，如 `fixture`、`harmony`、`user_selection`、`provided_context`、`host_fallback`。
- `t`、`x`：可选采样时间 / 到期时间，仅保留宿主声明，不以运行时间伪造采样时间。
- `q`：仅异常时提供。`b` = 已拦截，`m` = 真正缺参，`f` = 参数已给出但解析依赖未就绪，`r` = 已移除/未采用，`?` = 值来源未核实。

参数值仍在 `resolved.arguments`，审计不重复存完整取值。代码生成的来源记录不重新输入模型。本阶段没有偏好子系统，不生成虚假的“用户偏好”标签。

## 原文优先与系统补全

“查漠河现在湿度”中，漠河和现在标为 `U`。未获得命名地点的可信坐标时保留漠河，记录解析未就绪，不换成手机当前位置。“湿度呢”真正省略地点时，模拟手机定位标为 `S/fixture`；默认查询当前时刻标为 `D`，依赖系统时钟和时区 `S`。

原文有未核验空间目标或多个冲突地点时，仍要求澄清。除禁止新定位读取外，本次还阻止已经缓存的系统位置被填入该字段。显式目标不能因模型漏填就视为缺省。

只读用户选择标为 `C`；文件 MIME 根据已核验 URI 推导时标为 `R`，依赖 `file_id`。显式经纬度标为 `U`；为天气契约派生的 `location` 标为 `R`。必需业务目标未给时标为 `X/m`，不填系统当前值。电量等零输入 API 的查询值是输出，来源表为空，不生成伪入参。

`U` 只依据现有原文核对规则及合法片段生成，不因模型输出像真的、旧 resolver 说是 user、或某段字符串碰巧在原文中出现就宣称已核验。未覆盖的值保持 `X`，本次没有把有限规则扩充宣称为全面自然语言理解。

## 系统时间元数据与边界

宿主 `read()` 可选返回 `observedAt`、`expiresAt`；时间须为可解析字符串，保存到系统读取记录与来源审计。没有时间就不补造，没有来源就不冒充 HarmonyOS；PC 上仍为实验数据。

本次仅保留时间元数据，**尚未实现统一 TTL、过期自动重读、权限生命周期或真实业务执行门控**。来源可靠不证明目标存在、读权限已获批或数据仍新鲜。`X` 也不构成执行授权；当前 `ready_mock` 仍只表示模拟契约就绪。未来接真实执行器时必须独立检查来源、权限、时效和风险。

新增自动化测试覆盖原文地点、相对时间、系统/夹具来源、读取时间、缺参、阻止缓存兜底、嵌套字段、选择与派生、零输入、未核实值、网页转义及提示词结构不变。测试使用伪推理提供方，不新增大模型实测。

已有千题评测和所有历史原始证据保持不变。新源码与旧冻结快照不同，不能在旧批次中续跑新版本；原评测器仍按哈希拒绝混版。本次也将新来源模块与网页纳入后续源码冻结范围。来源展示和防兜底规则通过测试不等于模型 API/参数准确率已经提高。
