## 7. Laya影子与1384题后的请求复用

Laya为本机multilingual、0.4.6、CPU8线程，模型revision `7b928d828b7b0e022f929d9bd2e44165aa270148`；group16、maxChoices255、maxLen4096、headMaxLen768。它并行处理领域/API选择，但从不决定Qwen下游，也不生成参数。其API请求使用Qwen已选域与相同候选；Laya域选错不会构建它自己的下一阶段，因此本轮没有Laya独立端到端计划准确率。
