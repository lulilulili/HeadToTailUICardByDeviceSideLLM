# 2026-10-12 四模型全领域重测

本轮按用户明确选择加入 7B，范围为 10 领域 × 每领域 100 条 × 4 模型，共 4,000 次正式调用。固定顺序为 Qwen2.5 0.5B → 1.5B → 3B → 7B，每题一次，模型预热单列。题组原文、金标和固定 fixture 不改。

## 本轮改动

- 同步远端最新十领域、千题与参数来源实现。
- 提示词 `explicit-v8-cloud` 补充云端单记录 / 统计区分、路径 / 实例角色及预加载中文枚举映射。
- 校验无依据可选关联 ID 的残余阻塞、自然云端参数的否定与引号边界。
- 每轮有独立批次、源码快照及原始调用；页面和离线审核按本轮模型集合计算分母，历史三模型仍用自己的 3,000 计划数。
- 页面展示实际 PC 环境、模型规格与 CPU/GPU 驻留采样；模拟手机 fixture 单独说明。
- 切换批次时清除旧页面缓存，索引和详情带批次标识，避免新旧调用混用。

## 环境与固定条件

详细硬件、版本、模型 digest、采集边界和固定 fixture 见 [TEST_ENVIRONMENT_2026-10-12.md](TEST_ENVIRONMENT_2026-10-12.md)。本机为 Windows 11 专业版、i7-10700 / 8 核 16 线程 / 约 31.8 GiB 内存、Node 25.2.1、Ollama 0.35.0；四模型 Q4_K_M。实际 offload 在模型加载后记录。

固定 `unified`、`temperature=0`、`num_ctx=2048`、`num_predict=224`、请求超时 180 秒。运行中不调源码、用例、金标、提示词或推理参数；变更时拒绝在旧批次恢复。

## 启动与恢复

Windows 双击根目录 [启动全领域测试.bat](../../启动全领域测试.bat)。已在运行时复用并打开结果页；已中断时在相同冻结条件下恢复；已完成时显示完成提示，不重复推理。

首次新测试或明确要求另起一轮：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File edge-api-lab/start-full-test.ps1 -NewRun
```

启动脚本会先确认服务与模型条件，初始化独立 queued 批次，再用隐藏后台进程执行整轮并在完成后自动进行完整证据审核。每次调用、进度与原始 trace 持续落盘，不依赖当前聊天继续运行。

单独初始化 / 恢复的入口：

```powershell
cd edge-api-lab
node scripts/benchmark-single-service-100.mjs --new --initialize
node scripts/benchmark-single-service-100.mjs --manifest <本轮绝对manifest.json路径>
node scripts/verify-single-service-100.mjs --manifest <本轮绝对manifest.json路径> --partial --write-audit
```

进行中审核使用 `--partial`；正式完成后去掉该参数。部分分数只用已完成调用，未跑调用不算零分；正确澄清与解析失败不能叫真实服务执行成功。
