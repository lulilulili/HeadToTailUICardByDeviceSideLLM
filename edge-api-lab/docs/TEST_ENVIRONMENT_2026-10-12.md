## 固定推理与题组条件

- 套件 `single-service-100-v1`：10 领域各 100 条，共 1,000 条单服务中文请求。既有 100 条与新增 900 条分层统计。
- 领域：天气、日历、联系人、文件、服务入口、云端业务、设备、网络、位置、媒体。
- 一次调用模式 `unified`，每题一次；模型逐个串行处理相同固定题序。
- `temperature=0`、`num_ctx=2048`、`num_predict=224`、请求超时 180,000 ms。
- 每个模型的预热单独落盘，不计正式分数或耗时分位数；运行失败仍计入已完成调用分母。
- 本轮提示词为 `explicit-v8-cloud`；源码 / 规则 / 语料 / 模型 digest 在启动前冻结，不在推理中调整。
- 具体性能包括每次模型 wall/load/prompt/generation 耗时、输入输出 token、规则耗时及整机采样。百分比只使用已完成调用，未测模型为待测。

## 模拟手机状态与实际 PC 的区别

基准时间仍为 `2026-10-10T08:00:00+08:00`、时区 `Asia/Shanghai`，模拟手机位置为上海固定坐标 `(31.2304, 121.4737)`，网络句柄和音频场景也是 `fixture`。单题可以清空或覆盖相应依赖。固定时钟用于保持相对时间题的可比性，不代表测试当天真实时间。

没有读取这台电脑的 GPS，也没有接入 HarmonyOS 真机权限、实际联系人 / 日程 / 文件或真实云端业务。执行语义评分含正确澄清和解析失败；模拟就绪不等于真实业务执行成功。

远端文档中的 i5-8265U / 8 GB 及其 7B 超时结果属于另一台机器的历史验证，应与本轮 i7 环境分开阅读。

`data/runtime/single-service-100-active.json` 仅指向当前展示批次，历史文件保留。代码、金标、模型或题序不一致时拒绝恢复，以防混入不同条件。实际批次 ID 和启动验收另见 [本轮启动记录](RETEST_2026-10-12.md)。
